# Chatbot Administratif Intelligent — PFE 2025/2026

## Description
Portail administratif intelligent pour la gestion académique.
Développé avec Spring Boot 3, Angular 17 et FastAPI RAG.

## Auteurs
- Rania Gregba
- Asma Mbarek

## Technologies
- Backend : Spring Boot 3 + Java + PostgreSQL
- Frontend : Angular 17 + TypeScript
- Serveur RAG : FastAPI + ChromaDB + Groq API (Llama 3)
- Sécurité : JWT + BCrypt + Spring Security

## Fonctionnalités
- Authentification sécurisée (JWT + code 12 chiffres)
- Chatbot intelligent multilingue (FR/EN/AR)
- Génération automatique de documents (PDF/Word)
- Gestion des notes par professeur
- Emploi du temps automatique et manuel
- Gestion des filières, salles et matières
